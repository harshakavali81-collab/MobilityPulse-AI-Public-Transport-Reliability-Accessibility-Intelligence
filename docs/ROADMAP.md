# Roadmap and transparency checklist

## Implemented in the GitHub portfolio demo
- [x] Read-only FastAPI routes and stops
- [x] Explicitly synthetic transit catalogue
- [x] GTFS Schedule ZIP validation and import
- [x] Offline GTFS-Realtime protobuf diagnostics
- [x] Observed event on-time and headway calculations
- [x] Accessibility metadata labels
- [x] Offline RandomForest training with chronological holdout
- [x] React dashboard, charting, route schematic and feed health
- [x] Original 10-image SVG gallery
- [x] Docker Compose, tests, GitHub Actions
- [x] Power BI CSV exporter, docs and portfolio case study

## Not completed or not verifiable in a demo
- [ ] Contracted agency feeds and licensing review
- [ ] Verified real stop-event historical observations
- [ ] Continuous live vehicle-position data and ETA prediction
- [ ] Independently validated real-world forecasting
- [ ] Production database, auth, privacy and rate limiting
- [ ] Publicly deployed API and web service with uptime monitoring
- [ ] Direct Power BI `.pbix` file

These require data rights, infrastructure, credentials and operator-specific validation. Do not present them as finished.
